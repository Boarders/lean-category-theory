# lean-category-theory

Being a lean deveopment for various bits of category theory I happen to be interested in.

Some particular goals include developing:
- Enough of the theory of cartesian closed categories to cover semantics of STLC
- Developing the fibrational theories of system F
- Developing the 2-yoneda lemma for bicategories and using it to prove coherence of monoidal categories
- Developing the theory of lattices / pointless topology
- Developing the theory of sites and the canonical topology
- Some development of Grothendieck's galois theory

## Build

```
lake build CategoryTheory
```
